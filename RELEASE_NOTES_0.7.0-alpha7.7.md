# FibroChat v0.7.0-alpha7.7 — Stability & Security

## Что изменено

- Добавлен глобальный лимит API-запросов с ответом HTTP 429 и Retry-After.
- Публичные запросы на инвайт получили отдельный антиспам-лимит.
- Размер JSON-тела теперь проверяется до и во время чтения запроса.
- Добавлены CSP, Permissions-Policy, Cross-Origin-Resource-Policy и другие защитные заголовки.
- Добавлена структурированная серверная диагностика ошибок с traceId.
- Добавлен защищённый `/api/admin/diagnostics` для администраторов.
- В админ-панели появился блок диагностики БД, TURN, Push, realtime, сессий и вложений.
- Диагностика не возвращает секреты TURN или приватные ключи.
- Сохранена бессрочная подписка super_admin из Alpha 7.6.1.

## Настраиваемые лимиты

- `MAX_JSON_BODY_BYTES` (по умолчанию 524288)
- `API_RATE_WINDOW_MS` (по умолчанию 60000)
- `API_RATE_MAX_REQUESTS` (по умолчанию 240)
- `PUBLIC_INVITE_RATE_WINDOW_MS` (по умолчанию 600000)
- `PUBLIC_INVITE_RATE_MAX_REQUESTS` (по умолчанию 8)

Значения по умолчанию подходят для небольшого приватного узла.
- Усилены границы ролей: обычный admin не может блокировать другого admin или завершать его сессии; такие действия остаются за super_admin.
- Диагностика хранит до 100 последних необработанных серверных ошибок в памяти и показывает последние записи с traceId без секретов.
