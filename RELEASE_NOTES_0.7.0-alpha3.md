# FibroChat v0.7.0-alpha3 — UI Evolution

## Что изменено

- Полностью обновлена основная навигация FibroChat.
- Эмодзи-иконки заменены на единый набор встроенных SVG-иконок.
- Добавлен фирменный визуальный язык: матовые поверхности, мягкие световые акценты, спокойная типографика и новые состояния навигации.
- Карточка пользователя в боковой панели получила новый вид и индикатор защищённого контура.
- Экран диалогов получил собственную вступительную панель Fibro Space.
- Пункт «Администрирование» удалён из основного меню.
- Администрирование перенесено в «Настройки» и отображается только для ролей `admin` и `super_admin`.
- Для административного раздела добавлена раскрывающаяся карточка, не занимающая место у обычных пользователей.
- Существующие идентификаторы DOM и логика чата сохранены для совместимости с Reply, голосовыми сообщениями, вложениями и шифрованием.

## Проверка

Сборка подготовлена для развёртывания и проверки на сервере. Локальный запуск приложения не выполнялся согласно принятому рабочему процессу.
