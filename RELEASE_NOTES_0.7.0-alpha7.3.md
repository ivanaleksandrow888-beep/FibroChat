# FibroChat 0.7.0-alpha7.3 — Production Calls

- Temporary TURN credentials generated server-side using a shared secret.
- Static TURN credentials remain supported as a fallback.
- Call duration timer.
- Direct/TURN route indicator based on the selected ICE candidate pair.
- Basic audio quality indicator from WebRTC packet-loss and jitter statistics.
- Ten-second recovery window after a temporary disconnection.
- Coturn Docker Compose and Coolify setup guide.
