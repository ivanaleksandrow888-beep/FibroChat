# Test Report — FibroChat v0.7.0-alpha7.5

## Выполненные проверки
- `node --check` для серверных и клиентских JavaScript-файлов — пройдено.
- `npm run check` — пройдено.
- `npm run test:regression` — пройдено.
- `npm run smoke` на локальном JSON fallback — пройдено.

## Проверяемые сценарии
- Наличие публичного API запроса приглашения.
- Очередь одобрения администратора.
- Автоматическая обработка `?invite=` и `?request=`.
- Мастер настройки браузера, уведомлений и микрофона.
- Сохранение WebRTC, TURN, групп, нижней навигации Alpha 7.4.1.

## Ограничение стенда
Полный тест системных окон разрешений Android/iOS требует физических устройств и HTTPS-деплоя. Код использует стандартные Web API и отображает инструкции при системном запрете.
