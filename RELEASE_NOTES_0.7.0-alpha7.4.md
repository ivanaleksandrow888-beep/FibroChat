# FibroChat 0.7.0-alpha7.4 — UI Polish

## Изменения

- Основная навигация «Диалоги / Профиль / События / Настройки» возвращена вниз экрана на всех размерах дисплея.
- Навигация вынесена в самостоятельный нижний dock и больше не участвует в прокрутке страниц.
- Все страницы резервируют место под нижний dock: профиль, события, настройки и список диалогов не перекрывают кнопки меню.
- Рабочая область занимает весь viewport без внешних пустых полей.
- На desktop сохранена компактная верхняя полоса идентичности, а основной контент использует всю доступную ширину.
- На мобильном устройстве нижняя навигация скрывается только внутри открытого диалога, чтобы строка ввода занимала нижний край экрана.
- Добавлена лёгкая анимация переключения вкладок с поддержкой `prefers-reduced-motion`.
- При смене раздела его прокрутка возвращается к началу.

## Контрольный этап звонков

Реальное тестирование WebRTC на двух устройствах отложено до появления такой возможности. После теста нужно проверить STUN/TURN-маршрут и собрать браузерные и Coolify-логи при ошибке.
