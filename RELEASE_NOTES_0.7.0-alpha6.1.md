# FibroChat v0.7.0-alpha6.1

Завершающий корректирующий релиз для изменений Alpha 3–6.

## Исправлено
- Версия интерфейса, сервера, service worker и package metadata синхронизирована на `0.7.0-alpha6.1`.
- В сообщениях отображается отметка «изменено» при наличии `editedAt`.
- Текстовый эмодзи-замок в метаданных сообщений заменён SVG-иконкой.
- Добавлен полноценный интерфейс управления группой: изменение названия и описания, список участников, роли, удаление участников, добавление контактов, выход и удаление группы.
- Добавлены серверные методы добавления участника и удаления группы вместе с историей групповых сообщений.
- При переходе из группы в личный диалог кнопка управления группой скрывается, а вложения и голосовые сообщения возвращаются.
- Обновлён ключ кэша Service Worker, чтобы браузер не оставался на старом интерфейсе после деплоя.

## Проверки
- `npm run check`
- `npm run test:regression`
- `npm run smoke`

Все три проверки проходят успешно в JSON fallback режиме.
