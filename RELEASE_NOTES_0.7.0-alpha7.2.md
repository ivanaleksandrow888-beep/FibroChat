# FibroChat 0.7.0-alpha7.2

## Исправления аудиозвонков

- ICE-кандидаты теперь ставятся в очередь до установки remoteDescription и больше не теряются при раннем поступлении.
- Добавлена обработка состояний WebRTC и ICE с понятными статусами и тайм-аутом соединения.
- Добавлены исходящие гудки и входящий рингтон через Web Audio API без внешних аудиофайлов.
- Удалённое аудио принудительно запускается после получения медиапотока.
- Добавлены echo cancellation, noise suppression и automatic gain control.
- Добавлена серверная выдача ICE-конфигурации и поддержка TURN через переменные окружения.

## TURN-переменные окружения

- `TURN_URLS` — адреса через запятую, например `turn:turn.example.com:3478,turns:turn.example.com:5349`
- `TURN_USERNAME` — имя пользователя TURN
- `TURN_CREDENTIAL` — пароль/credential TURN

Без TURN звонки могут не проходить между некоторыми мобильными, корпоративными и NAT-сетями. STUN остаётся резервным вариантом.
