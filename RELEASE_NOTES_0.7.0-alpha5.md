# FibroChat v0.7.0-alpha5 — Message Management

## Добавлено
- Редактирование собственных текстовых сообщений с повторным сквозным шифрованием и новой цифровой подписью.
- Удаление собственных сообщений у обоих участников диалога через серверный tombstone-маркер.
- Поиск по текущему диалогу после локальной расшифровки сообщений в браузере; сервер не получает поисковый запрос и открытый текст.
- Метки «изменено» и «Сообщение удалено».
- Действия «Ответить», «Изменить» и «Удалить» непосредственно под сообщением.
- События реального времени `message:updated` и `message:deleted`.

## Ограничения
- Редактируются только текстовые сообщения. Вложения и голосовые сообщения можно удалить, но не заменить.
- Поиск выполняется только по уже полученному текущему диалогу.
- Удаление не стирает запись из резервных копий, созданных до удаления.

## Совместимость
- Формат существующих сообщений и E2EE сохранён.
- Новые поля `editedAt` и `deletedAt` необязательны для старых записей.
