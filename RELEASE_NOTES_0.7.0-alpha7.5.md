# FibroChat v0.7.0-alpha7.5

## Smart Invitations
- QR-код администратора содержит готовый одноразовый инвайт.
- QR-код обычного пользователя создаёт запрос головному устройству.
- После одобрения код автоматически подставляется на странице регистрации.
- Администраторы получили очередь запросов с действиями «Одобрить» и «Отклонить».

## Onboarding
- Пошаговая проверка браузера, уведомлений и микрофона.
- Android получает инструкцию для Chrome, iPhone — для Safari.
- Подсказки не показываются, когда рекомендуемый браузер уже используется.
- При запрещённых уведомлениях показывается платформенная инструкция.

## Ограничения платформ
Мобильные ОС не позволяют веб-сайту принудительно переключать браузер или напрямую открывать точный системный экран разрешений. FibroChat определяет окружение и показывает понятные пошаговые действия.
