# FibroChat v0.7.0-alpha7.1

## Alpha 7.1 — аудиозвонки и исправление интерфейса сообщений

- Добавлены аудиозвонки один на один через WebRTC.
- Сигнальный обмен offer/answer/ICE/reject/hangup/busy выполняется через защищённый API и существующий SSE-канал.
- Добавлены входящий вызов, принятие, отклонение, завершение и выключение микрофона.
- Звонки разрешены только между контактами; блокировки контактов учитываются сервером.
- Кнопки действий сообщения переведены в потоковую раскладку: они больше не перекрывают текст, вложения, цитаты, время и статус.
- Улучшены перенос длинных слов, ссылок и содержимого сообщений на мобильных экранах.

Примечание: для соединения WebRTC в сложных сетях может потребоваться собственный TURN-сервер. В этом выпуске используется STUN и прямое peer-to-peer соединение.
