# FibroChat v0.7.0-alpha6 — Encrypted Groups

## Добавлено

- создание групп из существующих контактов;
- список групп в боковой панели;
- роли участников: владелец, администратор, участник;
- серверные операции изменения роли и удаления участника;
- изменение названия и описания группы через API;
- текстовые групповые сообщения с клиентским шифрованием;
- отдельная зашифрованная копия сообщения для каждого участника;
- проверка цифровой подписи каждой копии на сервере;
- события реального времени и push-уведомления для групп;
- PostgreSQL-миграция `007_groups.sql`;
- JSON fallback-файлы для локального режима.

## Ограничения alpha6

- вложения и голосовые сообщения в группах пока отключены;
- управление составом и ролями подготовлено на сервере, расширенный экран настроек группы будет доработан отдельно;
- редактирование и удаление групповых сообщений пока не включено.

## Проверки

- `npm run check` — успешно;
- `npm run smoke` — успешно;
- запуск в JSON fallback — успешно;
- версия health endpoint — `0.7.0-alpha6`.
