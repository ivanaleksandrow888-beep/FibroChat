# FibroChat 0.7.0-alpha7.6.1

## Super Admin Lifetime Subscription

- Роль `super_admin` больше не зависит от `subscriptionEndsAt`.
- API возвращает `subscriptionLifetime: true` и не публикует дату окончания для суперадминистратора.
- Суперадминистратор не получает предупреждения об истечении подписки.
- Эндпоинт продления отклоняет попытку продлить бессрочную подписку.
- Клиент отображает «Подписка: бессрочно».

Существующий суперадминистратор получает бессрочный доступ сразу после деплоя; миграция данных не требуется.
